# Hiring, phase 1: implementation plan (2026-11-03)

Spec: `docs/superpowers/specs/2026-11-02-hiring-design.md` (signed off by the founder 2026-11-03: "proceed with
development of the hiring feature"). Decision D-141.

Approach: the deck RPC (`deck_candidates`) is left untouched. Hiring is a layer beside it: its own tables, owner-run
RPCs, and a client module that decorates cards the deck already loaded and lifts fitting cards from one suggestions RPC.
Before the migration is applied every hiring call fails with "function not found" and the client hides the feature.
